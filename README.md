# SerieApp
Film-app
En app för att hålla koll på filmer och serier. Man kan spara titlar med genre och status, och slumpa fram något att titta på när man inte kan bestämma sig.

Skolprojekt.

Funktioner
Spara filmer och serier
Ange genre för varje titel
Ange status (t.ex. sedd / ej sedd)
Slumpa fram en titel från listan
Ta bort eller ändra sparade titlar
Funkar på ett liknande sätt som letterboxd
Om tid finns
Filtrera slumpningen efter genre
Filtrera slumpningen efter hur mycket tid man har
Så funkar det
Alla titlar sparas i en lista. Varje titel har en genre och en status, så man kan se vad man redan har sett och vad som är kvar. Slumpfunktionen väljer en titel från listan åt användaren.

Kom igång
Instruktioner för att köra projektet lokalt läggs till när koden är på plats.
